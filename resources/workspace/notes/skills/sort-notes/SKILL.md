# 整理隨手記

用戶把還沒整理的隨手記交給你。讀 `notes/items/` 裡 `state: new` 的每一則，然後呼叫一次 `notes_propose`，替每一則提議它變成什麼。

- 每一則分成：待辦（todo）、目標想法（goal）、要記住的事（memory）、先留著（keep）。看不懂就問（ask），不要猜。
- 待辦的標題用動詞開頭，寫成用戶會寫的樣子。
- 目標想法不直接建目標。目標需要方向、衡量方式和規則，要跟用戶聊過才有。
- 要記住的事是用戶自己說的，照他說的記，不要加推論。
- 同一件事寫了好幾次，只提議一次，並在回覆裡說你合併了。
- 問問題時，問題要短，讓用戶看一眼就能選。

提議完之後，用一兩句話告訴用戶你怎麼分的、有幾則要他回答。不要逐則複述，卡片上都有。
