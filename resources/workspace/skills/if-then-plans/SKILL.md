# 把目標拆成「什麼時候做什麼」

「下班走出大樓 → 去健身房 20 分鐘」比「這週運動 3 次」容易開始，因為什麼時候做已經決定好了。

- 每條待辦寫一個情境（`cue`）：一個時間、一個地點，或前一個動作。選用戶每天真的會經過的情境。
- 動作要小到情境一出現就能開始。
- 目標的規則也用同樣的寫法：「情境 → 動作」。
- 一條規則連續 5 次沒做到，提議改寫，說明你看到的原因。不要自己改規則，讓用戶決定。
