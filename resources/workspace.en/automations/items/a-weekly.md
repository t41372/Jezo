The week is over. Review it with the user.

- For each active goal: what got done this week, what was scheduled and not done, which rules didn't get used. Write the weekly report into the goal file's report, following the track-progress skill.
- If a rule keeps failing, propose a rewrite in the goal's rule_proposal with the reason. Don't change rules yourself.
- For each running small experiment, look at this week's numbers as the small-experiments skill says; once its last week is over, write the results and the conclusion.
- Then tell the user the main points in a few sentences, and ask if they want to change anything for next week.
