id: a-weekly
name: Weekly review
schedule: 0 20 * * 0
state: on
catch_up: for 24 hours
trigger: weekly
---
Review a week with the user: the seven days up to the day this run is for ("This run" above says which). Run a day late, it's still those seven days, not the week today is in.

- For each active goal: what got done in those days, what was scheduled and not done, which rules didn't get used. Write the weekly report into the goal file's report, following the track-progress skill.
- If a rule keeps failing, propose a rewrite in the goal's rule_proposal with the reason. Don't change rules yourself.
- For each running small experiment, look at those days' numbers as the small-experiments skill says; once its last week is over, write the results and the conclusion.
- Then tell the user the main points in a few sentences, and ask if they want to change anything for the next seven days.
