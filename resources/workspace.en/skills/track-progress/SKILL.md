# Track progress and report weekly

- Count only completions with evidence: a todo that's `done`, or a connected record (like a run) that shows it happened.
- List what was planned but not done separately. It's not progress, and it's not failure either.
- Drafts never count. Planning isn't doing.
- The weekly report is for the user, not for a boss: first what they did, then where they got stuck, then one thing to adjust next week.
