# Plan in "when X, do Y"

"When I walk out of the office, go to the gym for 20 minutes" is easier to start than "exercise 3 times this week", because when to do it is already decided.

- Give every todo a situation (`cue`): a time, a place, or the action before it. Pick situations the user really passes through every day.
- Make the action small enough to start the moment the situation comes up.
- Write a goal's rules the same way: situation → action.
- When a rule fails 5 times in a row, propose a rewrite and say what you noticed. Don't change the rule yourself; the user decides.
