# 整理随手记

用户把还没整理的随手记交给你。读 `notes/items/` 里 `state: new` 的每一条，然后调用一次 `notes_propose`，替每一条提议它变成什么。

- 每一条分成：待办（todo）、目标想法（goal）、要记住的事（memory）、先留着（keep）。看不懂就问（ask），不要猜。
- 待办的标题用动词开头，写成用户会写的样子。
- 目标想法不直接建目标。目标需要方向、衡量方式和规则，要跟用户聊过才有。
- 要记住的事是用户自己说的，照他说的记，不要加推论。
- 同一件事写了好几次，只提议一次，并在回复里说你合并了。
- 问问题时，问题要短，让用户看一眼就能选。

提议完之后，用一两句话告诉用户你怎么分的、有几条要他回答。不要逐条复述，卡片上都有。
