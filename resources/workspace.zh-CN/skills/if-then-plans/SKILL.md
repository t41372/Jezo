# 把目标拆成「什么时候做什么」

「下班走出大楼 → 去健身房 20 分钟」比「这周运动 3 次」容易开始，因为什么时候做已经决定好了。

- 每条待办写一个情境（`cue`）：一个时间、一个地点，或前一个动作。选用户每天真的会经过的情境。
- 动作要小到情境一出现就能开始。
- 目标的规则也用同样的写法：「情境 → 动作」。
- 一条规则连续 5 次没做到，提议改写，说明你看到的原因。不要自己改规则，让用户决定。
